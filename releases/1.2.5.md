New (pfyangf fork)

Email verification codes
- Dynamic Island expand page can bind a mailbox and show verification codes from recent mail.
- Recognized codes show a large OTP with a Copy button and optional original-mail preview.
- When a code cannot be recognized, a preview page offers retry, copy selection, and open mail.
- Binding and show-on-island options live in settings for this page.

Updates
- In-app update checks now use https://github.com/pfyangf/BrimDeck releases (this fork), including update.json on v* tags.
- Settings project links and the installer update URL point at this fork.

新功能（pfyangf 二次开发）

邮箱验证码
- 灵动岛展开页可绑定邮箱，从近期邮件中识别验证码。
- 识别成功时大号显示验证码，并提供「复制验证码」与「预览原文」。
- 无法识别时进入预览页，可「重试识别」「复制选中」「打开邮箱」。
- 设置中可绑定邮箱，并开关是否在岛上展示等选项。

更新
- 应用内检查更新改为读取本仓库 https://github.com/pfyangf/BrimDeck 的 Release（含 v* 标签下的 update.json）。
- 设置中的项目链接与安装包更新地址指向本 fork。
