New (pfyangf fork)

Email codes inbox
- Optional Microsoft Graph mailbox bind (Azure AD public-client ID in Settings › Verification › Email codes) alongside the existing Outlook / Mail notification path.
- Optional IMAP bind for Gmail, QQ Mail, 163, Outlook.com, or a custom server. Passwords and app passwords are DPAPI-protected for the current Windows user.
- Expanded email page filters by All / Notifications / each bound account, previews recent mail, and copies recognized codes. Previous / Next switch messages reliably.
- Sync inbox now is available from settings.

Authenticator
- Clear Previous / Next buttons switch TOTP accounts. Swipe still works but only once per gesture so the current code card stays fully visible.

新功能（pfyangf 二次开发）

邮箱验证码收件箱
- 可在「设置 › 验证 › 邮箱验证码」绑定 Microsoft 账号（需填写 Azure 公共客户端 ID），与现有 Outlook / 邮件通知路径并用。
- 可绑定 Gmail、QQ、163、Outlook.com 或自定义 IMAP；密码与授权码用 DPAPI 仅保存在本机当前用户下。
- 展开页可按「全部 / 通知 / 各账号」筛选近期邮件并预览，识别到的验证码可一键复制；「上一条 / 下一条」切换更稳。
- 设置中可「立即同步收件箱」。

验证码（TOTP）
- 增加明确的「上一个 / 下一个」按钮切换账户；滑动仍可用，但每次按住只切换一次，保证当前验证码卡片完整显示。
