Fixed / Improved (pfyangf fork)

- **POP3 / IMAP bind dialog** follows Foxmail’s server tab: account, incoming host + SSL + port, optional outgoing SMTP (stored only; fetch still uses POP3/IMAP), STARTTLS toggle, and a keep-forever note (no DELE).
- Added **阿里云企业邮 / 万网** presets (`pop3.mxhichina.com` / `imap.mxhichina.com`, SMTP `smtp.mxhichina.com:465`).
- Expanded header **clock no longer overlaps** page icons when many pages are enabled on a narrow panel.
- Shortcuts **「添加快捷方式」** opens a file picker (`.exe` / `.lnk` / …) before the edit dialog; edit also has Browse.
