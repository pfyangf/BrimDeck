New (pfyangf fork)

- Settings › Verification › Email codes can bind **POP3** mailboxes alongside Microsoft and IMAP. Presets cover QQ, Foxmail, 163, 126, Yeah, Gmail, Outlook.com, iCloud, Yahoo, Aliyun, 139, Sina, Sohu, plus Custom host/port/SSL.
- Bound POP3 accounts poll recent inbox mail for the email-codes island the same way IMAP does. BrimDeck only reads messages over POP3 and does not delete them from the server.
- POP3 passwords / authorization codes stay DPAPI-protected for the current Windows user, same as IMAP. Existing Microsoft and IMAP binds load unchanged.

新增（pfyangf 二次开发）

- 「设置 › 验证 › 邮箱验证码」可绑定 **POP3** 邮箱，与 Microsoft、IMAP 并列。预设含 QQ、Foxmail、163、126、Yeah、Gmail、Outlook.com、iCloud、Yahoo、阿里云、139、新浪、搜狐，以及自定义主机/端口/SSL。
- 已绑定的 POP3 账号会像 IMAP 一样轮询近期收件箱，供邮箱验证码页使用。通过 POP3 只读取邮件，不会从服务器删除。
- POP3 密码 / 授权码仍用 DPAPI 仅保存在本机当前用户下，与 IMAP 相同。已有的 Microsoft、IMAP 绑定可继续加载。
