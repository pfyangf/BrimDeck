Fixed / Improved (pfyangf fork)

- Opening the island no longer stutters or rebuilds utility pages every clock tick. Messages / Alarm / Pomodoro / Memo / Shortcuts / Tools skip header and visual-tree work when nothing changed.
- Pomodoro no longer runs a one-second UI rebuild while a focus session is active: the service timer is idle unless a phase is running, and the open page paints the countdown in place (same idea as Authenticator).
- Alarm / Memo / Shortcuts cache their lists instead of re-reading disk on every expand tick.
- Toast inbox feeding runs only when the Messages page is enabled; mail-OTP-only polling is slower (5s) to cut background load.
- Mail soft-refresh no longer forces a full page rebuild every 30 seconds.
- Utility page timers stop as soon as the panel collapses; alarm / pomodoro toast ticks are wrapped so a notice failure cannot take down the dispatcher.

修复 / 改进（pfyangf 二次开发）

- 展开面板不再每秒整页重建工具类页面。消息 / 闹钟 / 番茄钟 / 备忘录 / 快捷方式 / 小工具在内容未变时跳过页头与视觉树重建。
- 番茄钟进行中不再每秒拆建界面：服务定时器仅在阶段运行时走动，打开页面时就地刷新倒计时（与验证码页相同思路）。
- 闹钟 / 备忘录 / 快捷方式缓存列表，展开时钟滴答不再反复读盘。
- 仅在开启「消息」页时写入通知收件箱；只开邮件验证码时轮询降为 5 秒，减轻后台负载。
- 邮箱页 30 秒软刷新不再强制整页重建。
- 收起面板立即停掉工具页定时器；闹钟 / 番茄钟通知异常不会拖垮 UI 线程。
