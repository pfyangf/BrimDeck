Fixed / Improved (pfyangf fork)

- Shortcuts list shows **icon + name only**. The full path is no longer shown in the row (still available in the tooltip and the Edit dialog).
- File / `.lnk` / `.url` entries use the Windows shell icon via the existing `ProcessIcons` cache (`SHGetFileInfo`); `.lnk` resolves to the target app icon (shortcut overlay OK).
- Missing paths and shell URIs fall back to a letter disc instead of crashing or leaving a blank slot.
- Icons are warmed when the store loads / changes so expand and refresh do not re-hit the shell every time.

修复 / 改进（pfyangf 二次开发）

- 快捷方式列表只显示 **图标 + 名称**，不再在行内展示完整路径（悬停提示与「编辑」对话框里仍可看到路径）。
- `.exe` / `.lnk` / `.url` 等走系统壳图标（复用 `ProcessIcons` 缓存；`.lnk` 取目标程序图标，可带快捷方式小箭头）。
- 路径失效或 shell URI 用字母圆标兜底，不崩溃、不留空位。
- 加载/变更时预热图标，展开与刷新不再每次反复查壳。
