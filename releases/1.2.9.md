New (pfyangf fork)

- Messages page: recent Windows notification banners from WeChat, QQ, Lark/Feishu, DingTalk, WeCom, and mail (toast inbox only; not chat history). Per-app toggles in settings.
- Alarm page: create / edit / enable / disable / delete local alarms; fires a Windows toast and system sound when due.
- Pomodoro page: focus / short break / long break timer with pause, reset, and configurable durations; optional end-of-phase notice.
- Memo page: short notes list with add / edit / delete, persisted locally.
- Shortcuts page: custom .exe / .lnk / shell URI launchers; click to open.
- Mini-tools page: JSON format/minify, text→QR, Base64 / URL / Hex encode-decode (offline dialogs).
- Every new page is off by default and can be shown, hidden, resized, and reordered under Expanded view › Pages shown.

新增（pfyangf 二次开发）

- 消息页：展示微信 / QQ / 飞书 / 钉钉 / 企微 / 邮件等发到 Windows 通知中心的最近横幅（仅通知收件箱，不是聊天记录）；设置里可按应用开关。
- 闹钟页：本地创建 / 编辑 / 开关 / 删除；到点弹出 Windows 通知并播放系统提示音。
- 番茄钟页：专注 / 短休息 / 长休息，支持暂停、重置与自定义时长；阶段结束可通知。
- 备忘录页：短笔记增删改，本地持久化。
- 快捷方式页：自定义 .exe / .lnk / shell URI，点击打开。
- 小工具页：JSON 格式化/压缩、文本转二维码、Base64 / URL / Hex 编解码（离线弹窗）。
- 以上页面默认关闭，可在「展开外观 › 显示的页面」中显示/隐藏、改尺寸与排序。
