# 验证码

BrimDeck 可以在设置里显示一次性验证码（TOTP），用来登录开启了两步验证的网站。

打开路径：**设置 › 验证 › 验证码**。设置窗口可以从展开面板右上角的齿轮、面板右键或托盘图标进入。

## 查看

每个账户一行：发行方、账户名、当前 6 位验证码，以及这一轮还剩多少秒。验证码大约每 30 秒更换一次，和常见身份验证器相同。剩余时间不到 5 秒时，进度条会改成提醒色。

默认算法是 HMAC-SHA1、30 秒、6 位（RFC 6238）。

## 添加

两种方式都可以，手动输入不依赖二维码：

1. **手动输入**。填写可选的发行方和账户名，以及 Base32 密钥（可以含空格），然后点“添加”。
2. **二维码**。点“从图片导入”，选择含 `otpauth://totp/...` 的 PNG、JPEG、BMP 或 GIF。也可以先把二维码图片复制到剪贴板，再点“从剪贴板导入”。

二维码里如果写了 SHA-256、SHA-512、6 到 8 位，或 15 到 120 秒的周期，会按二维码保存。HOTP（按次数递增的验证码）不支持。

## 删除

每一行的“删除”会先询问。确认后从本机列表移除，不能撤销。

## 密钥存在哪里

密钥写在 `%LOCALAPPDATA%\BrimDeck\otp.dat`。这个文件是整段账户列表的密文，使用 Windows DPAPI、范围为当前用户（`ProtectedData`，`CurrentUser`），和 API 密钥文件 `secrets.dat` 相同。磁盘上不是明文 JSON，其他 Windows 用户不能解密。

发行方和账户名也在这份密文里，只为了在列表中显示。验证码正文不上传，也不写入 `settings.json`。换一台电脑或删掉这个 Windows 用户的数据后，需要重新添加密钥。
